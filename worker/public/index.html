What we check

Discoverability

llms.txt on the API host or docs site, /.well-known discovery, robots.txt AI policy, a reachable spec.

Docs quality

Summaries, descriptions, request and response examples, API info.

Predictable errors

Documented 4xx and 5xx, one shared error schema, RFC 9457 problem+json.

Auth & identity

Security schemes, auth applied to operations, OAuth flows and scopes.

MCP-wrappability

Unique operationIds, parameter schemas, and the token cost of the generated tool list.

FAQ

What does the Agent-Ready Score measure?

How easily an AI agent can find, understand, call and recover from errors on your API, computed from its OpenAPI document and a few well-known paths. Five categories weigh 20% each: discoverability, docs quality, predictable errors, auth and identity, and MCP-wrappability.

How is this different from Cloudflare's or Postman's agent scores?

Cloudflare's Is It Agent Ready checks a website, and Postman's API Agent Score uses its own methodology across its network. Agent-Ready Score is open source, scores the OpenAPI document itself, runs in your CI, and reports what the API would cost in tokens as an MCP tool list. The numbers are not comparable one to one.

Where do you look for llms.txt?

On the API host first, then on the likely docs site: links in the spec (externalDocs, contact), docs.<domain>, the bare domain and developer(s).<domain>. For example, Stripe publishes llms.txt on docs.stripe.com.

Do you store my spec?

No. The spec is scored in memory and not saved. We fetch only the URL you give us and a few well-known paths on the API and docs sites.

Is it free?

Yes. The web scorer, the badge, the CLI and the GitHub Action are free and open source (MIT), with no sign-up. Pro is coming soon and has no price yet.
