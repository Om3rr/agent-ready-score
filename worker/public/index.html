FAQ

What makes an API agent-ready?

An agent has to find the API, understand each operation, parse its errors, authenticate with scoped credentials and fit its tools into a context window. We check llms.txt and /.well-known discovery, summaries and examples, RFC 9457 problem+json errors, OAuth scopes, unique operationIds, and the token cost of a generated MCP tool list.

How do popular APIs score?

On 20 November 2026 the median across 34 well-known public APIs was 63/100, and only 1 scored 80 or more. See every score and its fixes.

Is it free? Does it store my spec?

The web scan, CLI, GitHub Action and badge are free and MIT-licensed. The spec is scored in memory and not stored. We count anonymous button clicks (no IP, no email) to see which features matter.

How is this different from other agent-readiness checkers?

It is open source, it runs in your CI as a GitHub Action with a fail-under gate, and it measures what your API would cost in tokens as an MCP tool list. Other tools score docs sites or use their own network data; use whichever fits.

Checks: discoverability (llms.txt, OpenAPI, well-known, robots), docs quality, predictable errors, auth & identity, and MCP-wrappability. Use the CLI or GitHub Action in CI, and embed a README badge.
