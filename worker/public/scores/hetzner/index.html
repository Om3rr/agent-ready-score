Top fixes

  • fail No llms.txt at the origin
    Publish a short curated map at https://api.hetzner.cloud/llms.txt (see https://llmstxt.org) and point it at clean markdown copies of your API docs.
  • fail No well-known MCP, agent, OAuth, or API-catalog documents
    Add machine-readable discovery under https://api.hetzner.cloud/.well-known/: for example oauth-protected-resource, mcp.json or an MCP server card, and api-catalog.
  • fail No robots.txt at the origin
    Add https://api.hetzner.cloud/robots.txt and mention /llms.txt or your policy for AI crawlers (GPTBot, ClaudeBot, Google-Extended, and similar).
  • fail Errors are not advertised as application/problem+json
    Advertise `application/problem+json` (RFC 9457) on 4xx/5xx responses so agents get a consistent type, title, status, and detail.
  • fail No default or shared error response
    Define one error schema under components.schemas and reuse it via $ref, plus a `default` response on each operation.
