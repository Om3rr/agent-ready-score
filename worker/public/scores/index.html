FAQ

What is an Agent-Ready Score?

A 0-100 score of how easily an AI agent can find, understand, call and recover from errors on an API, computed from its public OpenAPI document and a few well-known paths on its origin. Five categories weigh 20% each: discoverability, docs quality, predictable errors, auth and identity, and MCP-wrappability.

How were these APIs scored?

Each public OpenAPI document was fetched and scored by the open-source agent-ready-score CLI on 20 November 2026. Discovery checks (llms.txt, /.well-known, robots.txt) ran against the API host listed. Re-run it yourself with scripts/score-leaderboard.mjs in the repository.

Why does a well-known API score low?

Big specs often lack examples, a shared error model and machine-readable discovery on the API host. Some companies publish llms.txt on their docs site rather than the API host. This snapshot only credited the API host; since 20 November 2026 the live scorer also checks the docs site (for example docs.stripe.com), so a re-score can come out higher.

Is this the same as Postman's API Agent Score?

No. Postman's score uses its own methodology across its network. This score is open source and computed from the public spec, so the numbers differ and are not comparable one to one.

How do I improve my score?

Publish /llms.txt, advertise application/problem+json errors with one shared schema, add examples to request and response bodies, expose /.well-known discovery documents, and keep operationIds unique. Gate it in CI with the free GitHub Action.
