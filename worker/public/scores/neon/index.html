Top fixes

  • fail No llms.txt at the origin
    Publish a short curated map at https://console.neon.tech/llms.txt (see https://llmstxt.org) and point it at clean markdown copies of your API docs.
  • fail No well-known MCP, agent, OAuth, or API-catalog documents
    Add machine-readable discovery under https://console.neon.tech/.well-known/: for example oauth-protected-resource, mcp.json or an MCP server card, and api-catalog.
  • fail No robots.txt at the origin
    Add https://console.neon.tech/robots.txt and mention /llms.txt or your policy for AI crawlers (GPTBot, ClaudeBot, Google-Extended, and similar).
  • fail Errors are not advertised as application/problem+json
    Advertise `application/problem+json` (RFC 9457) on 4xx/5xx responses so agents get a consistent type, title, status, and detail.
  • fail Generated tool list is expensive (35813 tokens, 195 operations)
    Split the API into smaller tool surfaces, shorten descriptions, and drop unused operations. A generated MCP server that exposes every path will overflow the context window.
