Top fixes

  • fail No llms.txt at the origin
    Publish a short curated map at https://api.resend.com/llms.txt (see https://llmstxt.org) and point it at clean markdown copies of your API docs.
  • fail No robots.txt at the origin
    Add https://api.resend.com/robots.txt and mention /llms.txt or your policy for AI crawlers (GPTBot, ClaudeBot, Google-Extended, and similar).
  • fail Many operations lack a useful description
    Write a `description` on each operation that says what it does, when to call it, and what it returns. Agents cannot ask a teammate.
  • fail Many operations have no examples
    Add `example` or `examples` on request bodies and success responses so agents can see a valid payload.
  • fail Many operations lack documented 4xx responses
    Document 400/401/403/404/409 responses with a schema so agents can parse failures instead of guessing.
